Курсовая работа «Ip Detector»
В Интернете часто ходит шутка, что можно вычислить по IP. Давайте реализуем эту шутку.

Цель:
Разработать Python-программу, которая:

определяет текущий IP-адрес пользователя;
получает географическую информацию по этому IP через внешний API;
сохраняет полученные данные в формате JSON;
загружает файл на Яндекс.Диск через REST API.
Задание:
С помощью сервиса ipify мы можем получить наш ip адрес
Далее через сервис ipinfo по api можем получить город, где находится этот ip адрес https://ipinfo.io/188.242.138.63/geo
Необходимо сохранить эту информацию в json файл и загрузить на Яндекс.Диск
Информация по Яндекс Диску есть а Полигоне Важно: Токен Яндекс.Диска публиковать в github не нужно!
Обязательные требования к программе:
Использовать REST API Я.Диска и ключ, полученный с полигона.
Для загруженного файла нужно создать свою папку на Я.Диске.
Код программы должен удовлетворять PEP8.
У программы должен быть свой отдельный репозиторий.
Все зависимости должны быть указаны в файле requiremеnts.txt.
Критерии оценки:
Выполнены обязательные требования к программе.
Для каждого сервиса написан свой класс с методами.
Вызов методов у класса происходит в функции main.
Во время выполнения программы отсутствуют ошибки.
После выполнения программы не появляются дополнительные файлы на компьютере.
json-файл загружен на Я.Диск
